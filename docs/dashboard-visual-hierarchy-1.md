# Dashboard Visual Hierarchy 1

## Scope

Frontend-only refinement of the accepted operational Dashboard contract. The backend projection, resume eligibility, workflow groups, client palette, task/review lifecycle, communications logic, and calendar model remain unchanged.

## Hierarchy Audit

| Section | Before | Intended importance | Change |
| --- | --- | --- | --- |
| Quick Actions | Seven saturated, equal-weight blocks | Primary entry point | Four light primary cards plus three quiet links |
| Itt folytasd | Correct but visually uniform | Highest operational emphasis | One restrained focus card or compact truthful strip |
| Operational cases | Dense table-like card | Primary intervention list | Grouped list, bounded to six visible cases |
| Daily work | Below the calendar | Concrete next work | Moved above the weekly preview under `Mai munkám` |
| Weekly preview | Large even when empty | Supporting schedule | Compact seven-day strip and inline empty state |
| Communications | Equal visual weight | Recent context | Lower-priority compact list |
| Further signals | Large lower panel | Optional signals | Slim disclosure, closed by default |

## Final Page Order

1. Page header
2. `Gyors műveletek`
3. `Itt folytasd`
4. `Ügyek, ahol lépés szükséges`
5. `Mai munkám`
6. `Napi események és határidők`
7. `Kommunikáció`
8. `További jelzések`

## Outcome

The page uses warm near-white depth, white working panels, subtle borders, restrained shadows, semantic workflow tones, and a narrow client identity accent. No KPI strip, `Beérkezési sor`, chart, backend request, or new product behavior was added.

Calendar redesign and Office News remain deferred.
