# Client Color Module Visual QA

Visual acceptance is incomplete because the current product has no relation-backed notification list that can satisfy the requested colored/neutral notification view. Dashboard, Communications, and Review use the same shared accent component, with a narrow decorative marker that leaves status, urgency, attention, and selected-state styles independent.

Required release-gate screenshots remain:

- Dashboard mixed-client rows at 1366x768 and 1440x900;
- Communications assigned/unassigned list and selected detail;
- Review queue and detail;
- a future explicit-relation Notifications list.

No production data or fake client relation was introduced to manufacture this proof.
