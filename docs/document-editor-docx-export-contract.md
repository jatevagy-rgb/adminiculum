# Document Editor DOCX Export Contract

## Supported output

Export validates the current editor JSON and generates a fresh `.docx` locally. It supports headings, paragraphs, marks, structured legal clause numbers as visible text, simple tables, page breaks, and field-token text policy.

## Not persistence

Export is a browser download. It does not save to the server, upload to SharePoint, clear dirty state, create a version, or update document metadata.

## Fidelity

The exported DOCX is usable but approximate. It is not the original file and is not Word-perfect.
