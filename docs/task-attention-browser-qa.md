# Task attention browser QA

## Required scenarios

- Populated workload block.
- All-zero workload block.
- Unclassified-only workload.
- Mixed explicit estimates and category defaults.
- Workload endpoint unavailable.
- Malformed workload response.
- Filter navigation.
- Task create/edit controls.

## Required viewports

- `1440×900`
- `1366×768`
- `1100×800`

## Current status

Browser QA remains required before production deployment acceptance. No fake production data should be added for this verification.
