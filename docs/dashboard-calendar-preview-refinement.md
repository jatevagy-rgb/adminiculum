# Dashboard Calendar Preview Refinement

The existing seven-day Adminiculum deadline preview remains intact and moves below `Mai munkám`.

## Visual Contract

- Compact seven-day strip.
- Selected day, date, and item count remain visible.
- Detail list renders only when the selected day has entries.
- Empty days show one compact inline message rather than a large nested pane.
- `Napi nézet`, `Heti nézet`, and `Új határidős feladat` retain their existing destinations.

The calendar still shows only persisted Adminiculum task/case deadline data. Monthly calendar work, external calendars, and data-model changes are deferred.
