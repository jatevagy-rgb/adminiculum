# Document archaeology

The document lineage is deep: storage foundation (`ed7d21c`), immutable versions (`ce55a80`), annotations (`7c9a23e`), work context (`68c8a7c`), comparison workspace (`4f03b86`), review (`d1d8fd6`), publication (`2975942`), and extraction/comparison recovery (`509412d`, PR94).

Canonical document versions are not a lost feature. The old editor working-copy/autosave semantics are intentionally incompatible with Word-primary and current security principles. The useful recovery is DOCX/PDF extraction and typed comparison with bounded formats, safe storage errors, object authorization, and scanner validation.
