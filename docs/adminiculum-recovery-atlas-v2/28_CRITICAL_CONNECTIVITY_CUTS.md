# Critical connectivity cuts

Ranked by expected number of existing capabilities unlocked:

1. **Case → Work Package snapshot/runtime** — unlocks case type, requiredness, initial tasks, task provenance, workspace runtime, and downstream time/progress.
2. **Communication → Case creation** — unlocks inbound intake, client assignment, responsible lawyer, case type, work package, and portal policy.
3. **Document → comparison extraction** — unlocks DOCX/PDF structured diff without rebuilding storage/version/review.
4. **Case → Portal grant/publication** — unlocks customer-visible case progress and internal-intake parity.
5. **Task/review → Time/workload** — unlocks operational economics without billing leakage.
6. **Document → Review decision** — joins existing versions/annotations to the operational review lifecycle.
7. **Organization → Portal workspace** — joins company profile/facts/compliance to customer-safe navigation.
8. **Fact → Finding → Proposal → Case** — turns compliance islands into case work.
9. **Outlook → attention/inbox projections** — turns gated inbound evidence into daily operations.
10. **Handoff/Clause/Legal analysis → case workspace** — surfaces existing specialist modules.
