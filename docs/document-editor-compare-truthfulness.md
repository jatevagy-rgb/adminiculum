# Document Editor Compare Truthfulness

## Current wording

Use: **Mentett források összehasonlítása**.

## What compare means now

The professional editor links to the existing compare route with real document/case identifiers where available. It does not include the current unsaved editor state and does not upload current browser content.

## Forbidden wording

Do not call this live track changes, current-session comparison, or Word tracked changes unless a real persisted change-operation/source model is implemented.
