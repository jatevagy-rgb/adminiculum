# Document Editor Keyboard and Accessibility

## Supported shortcut map

- `Ctrl/Cmd+B` — félkövér
- `Ctrl/Cmd+I` — dőlt
- `Ctrl/Cmd+U` — aláhúzás
- `Ctrl/Cmd+Z` — visszavonás
- `Ctrl/Cmd+Shift+Z` or `Ctrl/Cmd+Y` — újra
- `Ctrl/Cmd+F` — szerkesztőn belüli keresés
- `Enter` / `Shift+Enter` in search — next/previous result
- `Escape` — close search or panel mode

## Accessibility posture

Toolbar controls are buttons with Hungarian labels/tooltips. Search, file input, zoom, and focus-mode controls expose labels or button text. Future work should add browser-level visual smoke at 1366×768, 1440×900, and 1280×800.
