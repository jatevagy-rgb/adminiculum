# Dashboard Daily Work Layout

## Purpose

`Mai munkám` separates concrete assigned work from the case-level intervention overview.

## Panels

1. `Mai feladataim`
2. `Nekem kijelölt Review-k`
3. `Következő 7 nap határidői`

Large desktop uses equal-width aligned panels. Narrower supported widths may stack. Existing task and review filters remain unchanged; only the seven-day deadline presentation is bounded locally to the current day through the next six local days.

## Empty States

Empty states are inline panel content rather than bordered cards inside bordered cards:

- `Nincs mára kijelölt feladata.`
- `Nincs review-ra váró munkája.`
- `Nincs közelgő határidő.`

No fake counts, work items, or positive claims are introduced.
