# Noto Sans font for billing PDF exports

The billing PDF uses the included `assets/NotoSans-Variable.ttf` asset from
[Google Fonts' Noto Sans source](https://github.com/google/fonts/tree/main/ofl/notosans).
It covers the Hungarian characters used by the document and is embedded at
generation time; no operating-system font or network request is required.
